## Como adicionar mais

1. Faça upload do ficheiro original (pode ter fundo preto/branco/de cor, tal como o tem) diretamente para esta pasta no GitHub, com qualquer nome.
2. Avise-me — eu removo o fundo, ajusto a cor (preto → branco, se for esse o caso, para ficar visível no site escuro) e guardo com o nome de ficheiro certo acima.
3. Digo-lhe quando o logótipo já estiver a aparecer no site.
