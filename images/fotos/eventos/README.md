# Fotos do carrossel em Eventos

Cada uma das 3 secções de `eventos.html` (Casamentos, Eventos Corporativos, Eventos Sociais) tem um carrossel infinito de fotos à direita do texto, com 5 espaços cada. Coloque os ficheiros com estes nomes exatos — aparecem automaticamente, sem alterar código:

**Casamentos:** `casamentos-01.jpg` a `casamentos-05.jpg`
**Eventos Corporativos:** `corporativos-01.jpg` a `corporativos-05.jpg`
**Eventos Sociais:** `sociais-01.jpg` a `sociais-05.jpg`

Não precisa de ter as 5 fotos de cada — os espaços sem ficheiro mostram um fundo escuro elegante em vez de aparecerem partidos.
