# Por organizar

Fotos reais enviadas pelo utilizador (ficheiros originais `nuno1.jpg`...`nuno30.jpg`) que ainda não foram atribuídas a um espaço da galeria porque não é possível confirmar com certeza a que espaço/evento pertencem, ou porque a qualidade/enquadramento é mais adequado para uso pontual do que para um espaço fixo com nome de venue.

10 das 30 fotos originais já foram usadas (hero, retrato da biografia, "Dupla DJ + Músico" e 4 espaços da galeria confirmados por logótipos visíveis nas fotos: MAIN Lisboa, BBC Lisboa, Praia Verde, B Beach Oeiras, Água Moments Vilamoura, Gala Globos de Ouro).

Para usar uma destas fotos num espaço da galeria (ou noutro sítio do site), mova o ficheiro para a pasta certa com o nome exato esperado (ver `images/fotos/galeria/README.md` e o README principal do site) — ou diga-nos qual foto corresponde a qual evento/venue.
