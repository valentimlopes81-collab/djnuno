# Fotos do carrossel em Serviços

Cada uma das 3 secções principais de `servicos.html` (Dupla DJ com Músico, Dupla DJ com Cantora, Audiovisuais) tem um carrossel infinito de fotos à direita do texto, com 5 espaços cada. Coloque os ficheiros com estes nomes exatos — aparecem automaticamente, sem alterar código:

**Dupla DJ com Músico:** `dj-musico-01.jpg` a `dj-musico-05.jpg`
**Dupla DJ com Cantora:** `dj-cantora-01.jpg` a `dj-cantora-05.jpg`
**Audiovisuais:** `audiovisuais-01.jpg` a `audiovisuais-05.jpg`

Não precisa de ter as 5 fotos de cada — os espaços sem ficheiro mostram um fundo escuro elegante em vez de aparecerem partidos.
