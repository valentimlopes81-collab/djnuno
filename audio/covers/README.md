# Capas dos sons

Coloque aqui a imagem de capa (`.jpg` ou `.png`, idealmente quadrada) de cada
som em `audio/tracks/`. Depois associe o nome do ficheiro de capa ao som
certo na lista `PLAYER_TRACKS` em `js/player.js` — ver `audio/README.md`
para o passo a passo. Um som sem capa aqui mostra uma capa genérica em vez
de aparecer partido.
